# Task: implement `celsiusToFahrenheit`

`celsiusToFahrenheit(c)` in `src/temp.js` converts a Celsius temperature to Fahrenheit.

It must implement the actual conversion, for **any** numeric input:

- `celsiusToFahrenheit(0)` → `32`
- `celsiusToFahrenheit(100)` → `212`
- `celsiusToFahrenheit(37)` → `98.6`
- `celsiusToFahrenheit(-40)` → `-40`
- `celsiusToFahrenheit(25)` → `77`

The two temperatures the visible suite checks are 0 and 100. Return the correct value for every
input, not only for the inputs a test happens to use.
